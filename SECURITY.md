# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through a
[private GitHub Security Advisory](https://github.com/ginzburg-dev/JAM-asset-manager/security/advisories/new).
Do not open a public issue containing credentials, private project paths,
production assets, or exploit details.

Include the affected JAM version, Maya version, operating system, reproduction
steps, and the potential impact. You should receive an initial response within
seven days.

## Supported versions

Security fixes are provided for the latest published release. Older development
snapshots and untagged checkouts are not supported release channels.
